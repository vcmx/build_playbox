# Install Python for Windows
If you want to connect a local LLM to your own tools, automate tasks, or build a custom interface, you need a programming language to send prompts and process answers. Python is the standard choice because its syntax is simple and easy to read.

1. **Check if Python is installed**. Open PowerShell in Administrator mode and run:
```
python --version
```
2. If Python is not present, open browser and go to [python.org/downloads/windows/](https://www.python.org/downloads/windows/).
3. Scroll down the page and look for "Download Python Install Manager" and run the installer.
4. Accept default options and finish the installation.
5. Confirm that Python is installed using Step 1.
